LLMSystemInstructions: Based on the user message, suggest the appropriate system prompt and functions to use for processing the message in the best possible way.,
  parameters:
    - promptsList: "{promptsList}", // comment: it is going to be a MAP<String, String>
    where the key is a filename and the value is the content of the file.
    File content will be surrounded by open '[[[' and close ']]]' delimiters.
    - functionsList: "{functionsList}",
    - userMessage: "{message}"

## PROMPT SELECTION GUIDELINES:

For SIMPLE LOCATION REQUESTS (show me X, display X, I want to see X location):
- Use "LocationRequestPrompt.txt" (extremely efficient, ~30 tokens vs 1000+ tokens)
- Examples: "show me eiffel tower", "display grand canyon", "I want to see paris"

For COMPLEX TRAVEL PLANNING:
- Use "SingleQuestionPrompt.txt" or other detailed prompts
- Examples: "plan a trip to paris", "what should I pack", "recommend hotels"

Return entity MUST be in the form of JSON:
    List<String> functionNames - the list of required Functions' beanNames. Example: ["function1", "function2"].
    They MUST be in one word and THEY MUST be from the 'functionsList' list ONLY.
    potentially useful for current userMassage processing (could be several)
    String systemPrompt - MUST be a KEY of the required prompt content from the 'promptsList' Map (filename of the chosen system prompt)
    to be used as an instructions for use message processing (in combination with the suggested functionsList)
